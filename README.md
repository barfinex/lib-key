# @barfinex/key

**@barfinex/key** manages API keys and secure credentials for trading connectors.

---

## 🚀 Purpose

- Centralized key management.  
- Secure storage and retrieval of API credentials.  
- Support for multiple connectors and sandbox/production modes.  

---

## 📦 Installation

```sh
npm install @barfinex/key
```
